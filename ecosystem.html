01 The account

One account, every device

The durable idea behind OXIQEL is not any single device. It is one identity, one library, one set of cloud saves and one store account consumed by the console, the handheld, the cloud client and the headset alike. The services are designed as network services with documented interfaces, so each new device joins the same account instead of starting a new one.

SYS / 01

The system software

ONE, GO and CAST local streaming are designed on an immutable, image based Linux system with signed updates and atomic rollback, a gamescope class session for the television and handheld interface, and Vulkan as the native game interface. Windows games are addressed through a Proton class compatibility layer.

SYS / 02

Compatibility, stated honestly

Many Windows games run through a compatibility layer. Some do not, especially competitive multiplayer titles whose kernel level anti cheat refuses it, title by title, at the publisher's sole discretion. OXIQEL will maintain a per title tested database rather than a catalogue wide promise, and no compatibility is claimed for any title that has not been tested.

SYS / 03

Cloud streaming

The pilot design starts with local streaming inside the home, from your own console or PC to CAST or GO, at no service cost. A hosted cloud service is an economics question before it is a feature: streaming costs real money per hour, so no subscription price will be published before a pilot measures it.

02 OXIQEL DIRECT

OXIQEL DIRECT: ordering on evidence

DIRECT is the manufacturer connected order flow, designed and tested as a prototype gateway. Its rules are the product: an order is an offer to buy and is accepted only when the manufacturer confirms production capacity; payment states move only on the payment processor's confirmation; shipping states move only on carrier evidence; refunds complete only on processor confirmation. The gateway code passes its full local test suite, and it refuses live payment keys outright. No real manufacturer connection exists yet, because no manufacturer API exists until the quotation replies land.
